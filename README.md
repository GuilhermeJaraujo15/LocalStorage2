# Shopping Cart System (LocalStorage)

[English](#english) | [Português](#português)

---

## English

A JavaScript exercise focusing on LocalStorage, which involves saving small amounts of data directly in the browser. In this small project, it is applied to a shopping cart.

Project link: https://guilhermejaraujo15.github.io/LocalStorage2/

### Project Objective
Create a simple product page where users can add items to a shopping cart. The cart state must be saved in localStorage, ensuring that items remain there even if the user closes the browser and returns later. The cart should display a list of products, their quantities, the subtotal for each item, and the grand total.

### Core Features

1. Display a list of available products.
2. Allow users to add a product to the cart.
3. If a product is already in the cart, increase its quantity instead of adding it again.
4. Display the cart's contents in a separate section of the page.
5. Allow users to change the quantity of an item in the cart or remove it.
6. Dynamically calculate and display the total price of the cart.
7. Persist the entire cart state in localStorage.

## Português

Treino da vertente da linguagem JavaScript denominada LocalStorage, que diz respeito ao salvamento de pequenos dados no navegador. Neste pequeno projeto, o conceito é aplicado a um carrinho de compras.

Link do projeto: https://guilhermejaraujo15.github.io/LocalStorage2/

### Objetivo do Projeto
Criar uma página de produtos simples onde o usuário pode adicionar itens a um carrinho de compras. O estado do carrinho deve ser salvo no localStorage, permitindo que os itens permaneçam lá mesmo que o usuário feche o navegador e retorne mais tarde. O carrinho deve exibir a lista de produtos, suas quantidades, o subtotal por item e o total geral.

### Funcionalidades Principais

1. Exibir uma lista de produtos disponíveis.
2. Permitir que o usuário adicione um produto ao carrinho.
3. Se o produto já estiver no carrinho, aumentar sua quantidade em vez de adicioná-lo novamente.
4. Exibir o conteúdo do carrinho em uma seção separada da página.
5. Permitir que o usuário altere a quantidade de um item no carrinho ou o remova.
6. Calcular e exibir dinamicamente o preço total do carrinho.
7. Persistir todo o estado do carrinho no localStorage.
